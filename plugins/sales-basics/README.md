# sales-basics

Starter sales skills.

| Skill | Use it when |
|---|---|
| call-notes-summarizer | You have raw call notes or a transcript and want a consistent recap |
| follow-up-email | You want a customer-ready recap email after a call (works well right after call-notes-summarizer) |

Version history: see `version` in `.claude-plugin/plugin.json`. Bump it whenever you change a skill.
